# Multi-format design packages

In Export, choose **Export all formats as ZIP…**, then **Prepare ZIP package**.
Review the included files, omissions and expandable format notes. Download creates one
ZIP containing the safely validated machine files, README.txt and THREAD-SEQUENCE.csv.
Unzip before transferring a file appropriate to your exact machine. This is a design
package, not a claim of universal machine compatibility.

The six currently implemented and tested writers are PES, PEC, DST, EXP, JEF and VP3.
The available package list comes from the shared export capability registry. No HUS,
VIP or PHC writer is invented. Every file passes ordinary preflight, actual decoded
needle/pause verification and field checks before inclusion. VP3 with standalone STOP
and JEF designs reaching 200 mm remain blocked. A failed writer is named with its
reason; download requires reviewing the resulting omissions. No successful files
means no archive. Canceling downloads nothing and preserves the project.

The ZIP stores the exact generated bytes without rewriting coordinates, metadata,
colors or pause order. It uses locally vendored MIT fflate 0.8.3 with STORE entries,
avoiding expensive redundant compression. Generation is sequential and retained
machine-file bytes are bounded at 64 MB. The underlying application limit of 250,000
commands still applies. Unavailable formats can be exported separately after fixing
an applicable issue; the package never silently removes a construction stop.

The README reports actual generated bounds, stitches, changes/stops, included/omitted
formats and limitations. Its ordered thread chart includes physical spool snapshots
where assigned, and ordinary design colors otherwise. Operator stops remain explicit.
Source-plan counts can differ from format-specific counts when a writer splits a long
movement; those additions are reported. Colors remain approximate; DST/EXP do not
embed palettes, JEF/PEC use fixed palettes, and EXP companion files are not created.
Keep the CSV and consult the machine manual. Physical sew-out testing is still required.

Reference rasters, editable source artwork, full catalogs and personal inventory are
not included. Keep your .embstudio project separately. ZIP export preserves the current
preview; individual machine-file export continues to display its decoded instructions.
