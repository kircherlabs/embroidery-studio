Input compatibility does not mean a writer exists, that every feature is preserved, or that this release was physically sewn on that model. JEF+/JPX/PHC/SEW/PCS/XXX remain documented inputs only, not new exporters. Existing export safeguards still apply to JEF large fields and VP3 stops. For the new field-only Pfaff/Viking/Singer entries, choose a format only after checking the exact manual; no brand-based format assumption was added.

Find a model searches all brands; selecting it updates Brand → Model → Hoop. Optional magnetic hoops are listed only for models named in their manufacturer compatibility evidence. Included/optional status is omitted where not reliably established. The app remains usable with Generic / Custom dimensions.
